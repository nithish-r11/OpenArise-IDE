Installation Instructions

Get started in five straightforward steps.

1

Download OpenArise IDE

Choose between the standard Windows installer or the portable executable from the download section above.

2

Install OpenArise IDE

Run OpenAriseIDE-Setup-1.0.0.exe and follow the installation prompts. No administrator privileges are required.

3

Install Ollama

Download and install the official Windows Ollama client from ollama.com/download/windows.

4

Download Coding Model

Open PowerShell or Command Prompt and download the recommended coding model:

PS> ollama pull qwen2.5-coder:7b
5

Start Coding with AI Agent

Launch OpenArise IDE, click Open Folder, and enter your natural-language task in the AI Agent panel. Need help? Read our Ollama Setup Guide.

OpenArise IDE – Overview & README

v1.0.0

OpenArise IDE is a fast, reliable, local-first AI development environment designed to provide a Cursor-level coding workflow powered by local large language models.

Key Architectural Principles

  • Local-First Privacy: Your source code never leaves your computer. All AI reasoning is executed locally via Ollama.
  • Minimal Main Toolbar: Contains strictly four buttons in exact order: Open Folder, New File, Save, Run Python. Advanced tools remain accessible via top menus and Command Palette (Ctrl+Shift+P).
  • Robust Multi-File Staging: Multi-file operations are staged into an atomic journal and presented for user approval in an interactive Diff Review dialog.

Ollama Setup & Model Configuration Guide

Prerequisite

OpenArise IDE connects to a local Ollama daemon running on http://127.0.0.1:11434. Follow these instructions to configure your environment.

1. Install Ollama

Download the official installer from ollama.com/download/windows and run the installer. Verify it is running by executing:

ollama --version

2. Pull Recommended Models

ModelParametersSystem RecommendationPull Command
qwen2.5-coder:7b
(Recommended Default)		 7.6B 16 GB RAM / 6GB+ VRAM ollama pull qwen2.5-coder:7b
qwen2.5-coder:1.5b
(Fast / Low-Spec)		 1.5B 8 GB RAM / Any CPU ollama pull qwen2.5-coder:1.5b
deepseek-coder:6.7b 6.7B 16 GB RAM / 6GB+ VRAM ollama pull deepseek-coder:6.7b

3. Verify Connectivity

In OpenArise IDE, check the bottom status bar for Ollama: Connected. Select your model from the dropdown in the AI Chat or AI Agent panel.

Troubleshooting & Diagnostics

Self-Help

Status Bar Shows "Ollama: Disconnected"

The local Ollama service is not running or listening on port 11434.

  • Open PowerShell and run ollama serve to start the service manually.
  • In OpenArise IDE, choose AI > Refresh Models or wait for the automatic background check.
  • Confirm port 11434 is not blocked: Get-NetTCPConnection -LocalPort 11434.

Agent Task Latency on CPU

Local 7B models generate approximately 10–20 tokens/second on standard multi-core CPUs. For faster execution on low-spec PCs, switch to qwen2.5-coder:1.5b in the model dropdown.

Terminal Port Conflicts

If a local web server (e.g., python -m http.server 8000) fails because the port is already in use, click Stop in the terminal toolbar to terminate running processes, or run:

Get-Process python | Stop-Process -Force
